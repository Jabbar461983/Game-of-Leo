# ⚔️ Game of Leo

Ein spannendes browserbasiertes Spiel, bei dem du Gegner besiegen musst, um neue Levels freizuschalten. Entwickelt mit HTML5, CSS3 und JavaScript.

## 🎮 Features

### Gameplay
- **10 verschiedene Welten** mit eigenen Themen: Gift, Wasser, Feuer, Erde, Eis, Sand, Leere, Donner, Holz und Chaos
- **5 Level pro Welt** + Boss-Battle
- **Progressive Schwierigkeit** - immer mehr und schnellere Gegner
- **Smooth Steuerung** - optimiert für Tastatur und Touch-Geräte

### Charaktere
- **Magier** 🧙‍♂️ - Schießt magische Blitze
- **Prinzessin** 👑 - Schießt explodierende Münzen
- **Schwertkämpfer** 🛡️ - Kämpft mit Schwert und Schild

### Spielmechaniken
- **100 Leben** pro Level (wird nach jedem Level zurückgesetzt)
- **-1 Schaden** pro Treffer von Gegnern
- **Gegner-Vielfalt** - Skelett-Bogenschützen, Fledermäuse, Geister, Zombies, Spinnen
- **Verstecke** - Gebüsch, in dem Gegner dich nicht sehen
- **Luftdrop-Kisten** - Fallen von Flugzeugen mit Sandwiches (+20 Leben)
- **Boss-Kämpfe** - Jeder Boss hat einzigartige Angriffsmuster

### Progression
- **Superkräfte** - Nach jedem Boss-Sieg erhältst du eine neue Fähigkeit
- **Waffen-Auswahl** - Nach jedem Level kannst du eine neue Waffe wählen
- **Rangliste** - Sehe deine besten Platzierungen und die anderer Spieler

## 🎯 Steuerung

### Desktop
- **WASD oder Pfeiltasten** - Bewegung
- **Maus klicken** - Schießen (in Richtung des Cursors)
- **E** - Verstecken im Gebüsch
- **ESC** - Pause

### Mobile
- **Linker Bereich des Bildschirms** - Bewegungs-Joystick
- **Rechter Bereich des Bildschirms** - Schießen

## 📋 Gegner

| Gegner | HP | Schaden | Besonderheit |
|--------|----|---------|----|
| Skelett-Bogenschütze 💀 | 20 | 1 | Schießt von weitem |
| Fledermaus 🦇 | 10 | 1 | Schnell und wendig |
| Geist 👻 | 15 | 1 | Kann durch Wände gehen |
| Zombie 🧟‍♂️ | 30 | 2 | Langsam aber stark |
| Spinne 🕷️ | 25 | 2 | Springt herum |

## 👹 Bosse

Jede Welt endet mit einem Boss, der drei verschiedene Angriffsmuster hat:

- **Giftkönigin** (Welt 1) - Giftschuss
- **Wassergolem** (Welt 2) - Wasserwelle
- **Feuerdämon** (Welt 3) - Feuerball
- **Erdtitan** (Welt 4) - Erdstachel
- **Eiskönig** (Welt 5) - Gefrierung
- **Sandpharaoh** (Welt 6) - Sandsturm
- **Voidlord** (Welt 7) - Dimensionsloch
- **Sturmgott** (Welt 8) - Blitzschlag
- **Waldgeist** (Welt 9) - Dornenranken
- **Chaosmacht** (Welt 10) - Totale Zerstörung

## 🚀 Installation

1. Klone das Repository:
```bash
git clone https://github.com/Jabbar461983/Game-of-Leo.git
```

2. Öffne `index.html` in deinem Browser

Das Spiel benötigt keine Installation und läuft vollständig im Browser!

## 💾 Speicher & Rangliste

Das Spiel speichert deine Ranglisten-Einträge automatisch im Browser-Speicher (localStorage). Diese Daten bleiben auf deinem Gerät gespeichert, bis du sie löschst.

## 🎨 Anpassung

Das Spiel nutzt CSS-Variablen für das Styling. Um die Farben anzupassen, bearbeite die `:root` Variablen in `css/style.css`.

## 📱 Browser-Kompatibilität

- Firefox 60+
- Safari 12+
- Edge 79+
